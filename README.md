# Week 1 - .NET Backend Development

My first week at BinX Tech was about building the foundation before starting backend development with ASP.NET Core.

The focus was mainly on understanding C#, how .NET projects work, how to structure code properly, and how developers manage their work using Git and GitHub.

---

## Day 1 - Starting with .NET

I started by setting up my .NET environment and getting familiar with the tools I will use throughout the internship.

I practiced creating, building, and running .NET console applications using the dotnet CLI.

Commands I worked with:

- dotnet new
- dotnet build
- dotnet run

This helped me understand the basic workflow of a .NET project and how the development environment works.

---

## Day 2 - C# Fundamentals

This day was about understanding the basics of C# instead of only writing code that works.

I practiced:

- Value types and reference types.
- Variables and type inference.
- Conditions and loops.
- Nullable reference types.

The value type vs reference type topic was one of the most important parts because it helped me understand how data is stored and passed in C#.

---

## Day 3 - Object-Oriented Programming

This was the day where I started thinking more about designing code.

I practiced:

- Creating classes.
- Using properties and constructors.
- Applying encapsulation.
- Working with interfaces.
- Understanding inheritance and polymorphism.
- Using records for data models.

For practice, I built a small Library System where I created:

- Book class.
- Member class.
- BorrowRequest record.

The goal was not just making the program run, but organizing the code in a way that can be extended later.

---

## Day 4 - Collections and LINQ

I learned how to work with different types of collections and choose the right one depending on the situation.

I practiced:

- List for storing ordered data.
- Dictionary for accessing data using keys.
- HashSet when uniqueness is needed.

I also started using LINQ to write cleaner queries instead of writing long loops.

Examples I practiced:

- Filtering data.
- Selecting specific values.
- Sorting results.
- Counting and calculating values.

I also learned the basics of async/await and why asynchronous programming is important in backend applications.

---

## Day 5 - Git and GitHub Workflow

The last day was about learning how developers manage their code in real projects.

I practiced the Git workflow:

```
Create Branch
      ↓
Make Changes
      ↓
Commit Changes
      ↓
Push to GitHub
      ↓
Open Pull Request
```

Commands I practiced:

```bash
git status
git branch
git switch
git add
git commit
git push
```

I learned why developers use feature branches instead of directly working on the main branch. This keeps the main branch stable and makes it easier to review and manage changes.

I also learned the importance of writing clear commit messages because they explain what was changed and help other developers understand the project history.

Pull Requests were another important part of this workflow. I learned how they allow developers to review changes, discuss improvements, and merge code safely into the main branch.

---

## Week 1 Summary

After completing my first week, I have a better understanding of the foundation needed for backend development using .NET.

During this week, I moved from writing simple C# code to understanding how real projects are structured, designed, and managed.

The main concepts I practiced were:

- .NET project setup and CLI commands.
- C# fundamentals and nullable reference types.
- Object-oriented programming concepts.
- Collections, LINQ, and async/await.
- Git and GitHub workflow.

The biggest thing I learned is that backend development is not only about writing code that works. It is also about writing organized code, choosing the right approach, and following a professional workflow.

This week gave me the foundation I need to continue learning ASP.NET Core and start building more advanced backend applications.
